Craft categories

A card can sit in more than one category when it earns them.

  • Typography: fonts, hierarchy, calm type
  • Color: palette, accents, restraint
  • Layout: structure, spacing, page flow
  • Roundness: corners, pills, soft geometry
  • Atmosphere: gradients, blurs, fading
  • Imagery: texture, photo, illustration
  • Filter out: negative examples only

Cards

  • Real thumbnail when possible
  • Short steal note (what to take, what to remap or skip)
  • Craft tags, not industry labels
  • Link to the live shot or site
  • data-approved="true" for director-approved picks

Board UI

  • One heading per section. No section subtitles.
  • No overlay badges on thumbnails.
  • Compact pill tags (do not stretch into circles).
  • No hero eyebrow / date chrome.
